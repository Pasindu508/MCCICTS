--------------------------------------
About This Desktop
======--------------------------------

This interactive web desktop is the official MCCICTS portal,
built on a Windows 98-inspired interface. Explore built-in
apps, customize themes, and learn about our society's work
in web development, UI/UX design, cybersecurity, and more.

--------------------------------------
Our Focus Areas
======--------------------------------

- Web Development (React, Next.js, TypeScript)
- UI/UX Design
- Cyber Security & digital safety
- Mobile Apps, AI/ML, Robotics, and Graphic Design

--------------------------------------
Included Software
======--------------------------------

This desktop bundles classic Windows 98 applications recreated
for the web, including Paint, Notepad, Calculator, Minesweeper,
Solitaire, Pinball, Winamp, Explorer, and more.
