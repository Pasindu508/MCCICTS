MCCICTS Themes & Wallpapers
===========================

Themes (double-click to apply colors):
  - MCCICTS Teal.theme   — official society teal & navy palette
  - MCCICTS Navy.theme   — darker navy variant

To change the wallpaper the Windows 98 way:
  - Right-click the desktop and choose "Properties", or
  - Start > Settings > Display Properties
Then pick a wallpaper on the Background tab, choose a Display mode
(Center, Tile, or Stretch), and click Apply or OK.

You can also open Paint and use File > Set As Wallpaper.

Wallpapers live in /images/wallpapers/ on the web server:
  - Windows Default I.png   — solid society teal
  - wallpaper with logo.png — teal with the MCCICTS crest
  - mccicts-teal.svg        — branded gradient with society name

Visit https://mccicts.lk for more about our society.
