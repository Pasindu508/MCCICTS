MCCICTS Themes & Wallpapers
===========================

Themes (double-click to apply colors):
  - MCCICTS Teal.theme   — official society teal & navy palette
  - MCCICTS Navy.theme   — darker navy variant

Wallpapers are in /images/wallpapers/ on the web server.
To set a wallpaper, open Paint, create or open an image, then use
File > Set As Wallpaper (Tiled) or (Centered) from the desktop integration.

Included wallpapers:
  - mccicts-teal.svg     — branded gradient with society name
  - mccicts-circuits.svg — tech grid pattern
  - mccicts-campus.svg   — stylized college illustration

Visit https://mccicts.lk for more about our society.
